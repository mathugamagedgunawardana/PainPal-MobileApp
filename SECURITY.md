# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Email **security@painpal.dev** (replace with your team inbox before launch).

We aim to acknowledge within **72 hours** and provide status within **14 days**.

## Scope

In scope: auth bypass, insecure local storage, token leakage, API misuse from the mobile client.

## Privacy Reminder

Never include real patient information (PHI) in issues, PRs, or reports.

See also [PainPal-Web/SECURITY.md](https://github.com/YOUR_ORG/PainPal-Web/blob/main/SECURITY.md) for platform-wide policy.
